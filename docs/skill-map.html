판단에 따라 오가는 작업 지도입니다.
성공 조건과 대안을 정한 뒤 결과를 검증합니다.

판단 요소를 누르면 관련 스킬로 이동합니다. 원인과 개입 지점은 문제 정의에서 연결하고, 요구사항은 변화가 만족해야 할 조건을 정합니다.

      학습할 때만 · 내 말로 설명하는 연습
      내 최초 설명을 먼저 남긴 뒤 피드백을 받습니다. 일반 업무 검증에는 답변 대기 절차를 추가하지 않습니다.
      설명 연습 모드로 진행해줘.
내가 먼저 목적·선택 이유·검증 사례·한계를 설명하면,
최초 답변을 보존하고 빠진 근거나 논리를 피드백해줘.
      
      
      
    
      
  
      
  
      제출 전, 내 말로 설명하기
      잘 쓴 결론과 실제로 확인한 범위를 함께 남깁니다.
      1. 어떤 문제를 왜 선택했는가?
      2. 어떤 자료의 무엇을 무엇과 비교했는가?
      3. 내가 직접 확인한 것과 AI만 확인한 것은 무엇인가?
      4. 아직 모르는 것과 판단을 바꿀 새 증거는 무엇인가?
      
  
      01
      사실 · 해석 · 가설을 구분
      담당자 응답은 과제 내 근거입니다. 지원 AI가 만든 예시를 실제 응답으로 채우지 않습니다.
      02
      검증은 중간에도
      핵심 수치와 주장은 그때 확인합니다. 기능 시험 통과와 실제 업무 효과는 구분합니다.
      03
      요구된 범위에서 끝내기
      문제 발굴만 요구되면 그 근거를 검증해 제출합니다. 해결안·구현은 요구될 때 이어갑니다.
      
  
      사용자가 제시한 담당자 페르소나 인터뷰 상황을 위한 학습용 운영안입니다. 공식 출제 유형이나 평가표가 아닙니다. 로컬 스킬·개인 AI의 시험 사용 허용 여부는 실제 응시 지침을 따릅니다.
