- 버전: r1
- 과제: 신규 고객 온보딩 상태 확인의 부담을 검토하고 작은 개선안을 제안한다. 기존 공유표를 활용하며 신규 유료 서비스 구매는 제외한다. 문의 대응뿐 아니라 정보 갱신을 포함한 전체 직접 업무 시간을 늘리지 않는 것을 요구한다.
- 실제 참여자 합의, 업무 시간 측정값, 실험 실행 결과는 제공하지 않는다.
