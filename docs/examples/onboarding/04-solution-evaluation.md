## 5. 추천과 선택

- AI 추천과 이유: S-01. 중간 확인 업무를 추가하지 않고 O-01에 직접 대응하는 가설을 먼저 시험한다.
- 사용자 선택 또는 위임: 아직 없음.
- 현재 선택 상태: 제안.
- 산출물 작성 범위: 비교·시험 계획만 작성. 운영·구현은 실행하지 않음.
- 선택을 바꿀 증거: 갱신 담당자가 변경을 알 수 없거나 입력 부담 증가가 R-02를 위반하는 경우. 최신 정보가 있어도 문의가 지속되면 M/O부터 재검토.
