# 협업·결정 기록

작업명: {{작업명}}

이 문서는 협업 중 **무슨 내용이 오갔고 왜 어떤 결정을 했는지** 보존한다. 최종 실행 범위와 순서는 `docs/PLAN.md`, 단계별 근거·분석·검증은 해당 산출물에서 관리한다.

## 기록 규칙

- `나`는 사용자, `Codex`는 분석·실행 에이전트, `담당자`는 인터뷰 대상이다. 가상 담당자는 `담당자(페르소나)`로 구분한다.
- 실제 질문·응답·제안·선택·위임·범위 변경·검증 결과를 해당 응답이 끝나기 전에 남긴다. 모든 도구 호출의 전문을 기록하지 않는다.
- 시각에는 시간대를 쓴다. 발화 시각이 없으면 `발화 시각 미확인; 기록 시각 YYYY-MM-DD HH:mm ±HH:mm`로 적는다. 추정 시각을 실제 발화 시각으로 쓰지 않는다.
- `결정` 셀에 안정적인 D-ID와 상태를 붙인다. 예: `D-001 · 제안`, `D-002 · 확정`, `D-003 · 위임에 따른 결정`, `D-004 · 미결정`, `D-005 · 검증 결과`.
- AI 제안과 실제 사용자 결정은 구분한다. 한 사람이 동의한 범위를 다른 사람의 합의로 확대하지 않는다. 변경·철회는 새 행에서 기존 D-ID를 참조하고 이전 행을 보존한다.
- 근거에는 실제 발언의 요약·대화 위치 또는 상대 링크·사용 버전·항목 ID를 적는다. 민감 정보와 원자료 전문은 복사하지 않는다.
- 아래 표는 빈 기록 양식이다. 실제 협업이 발생한 뒤에만 행을 추가한다.
